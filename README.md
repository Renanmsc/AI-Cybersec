# Privacy Tracker Detector

Extensão Firefox para detecção de rastreadores e análise de privacidade.

## Como carregar

1. Abra o Firefox.
2. Acesse `about:debugging`.
3. Clique em "Este Firefox".
4. Clique em "Carregar extensão temporária".
5. Selecione o arquivo `manifest.json`.

## Estado atual

Versão inicial da extensão, contendo:

- estrutura básica;

- comunicação entre página e extensão;
- carregamento no Firefox.
